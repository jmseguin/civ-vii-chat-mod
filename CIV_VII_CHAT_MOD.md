# Agent Chat Mod

Create a mod that can be optionally used in the game between teammates including bots on that team.

## Details

- It should appear in the Sub-System Navigation Dock (Top Left HUD) similar to "Drongo's City Planner" mod.
- It offers a conversation display area holding this game's conversation and needs to scroll.
- It offers an input box at the bottom of the pane below the conversation display area (and some padding)
- It offers a send message button that looks like a right arrowhead
- In the conversation display area, each partipant's message needs to be clearly marked by their player name/number so the other players know who they are talking to
- The input area supports @ which then allows a player to direct a message to a specific teammate in the form of @<player name/number>. This @ tag will prefix the message in the conversation display area.
- Create an appropriate civ vii styled icon for our mod and for the "send message" button
